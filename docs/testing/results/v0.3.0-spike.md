## Findings that change the design

- **Grep and Glob don't exist as separate tools in this Claude Code version.** Search goes through Bash. Listing them is harmless (they are ignored), so the agent files list them for versions that have them, and rely on Bash otherwise.
- **`Skill` must be listed** in limited agents. The test agent didn't get it, so the reviewer couldn't have run the `security-review` skill. The reviewer's list adds `Skill` and `ReportFindings`.
- **A Bash-capable agent is not strictly read-only.** With Bash, the reviewer and the scout could still write through the shell. The guard hook and the PM's permission mode still apply to those commands (row 6).
- **Aliases follow the Claude Code version.** On 2.1.236, `opus` resolved to Opus 5 and `sonnet` to Sonnet 5; newer versions resolve them to the 5.5 models. We keep aliases so the plugin moves with Claude Code.

## Not tested here

- The guard's "ask" decision inside an agent for a risky command. The agent wouldn't run one without the PM's own yes, which is correct. The guard's matching is unit-tested (`tests/test_guard.py`), and row 6 shows the same script runs for agent calls.
