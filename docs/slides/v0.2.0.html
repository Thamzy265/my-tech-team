Problem

Today you do too much of the checking

Today

  • QA hands you 10-step manual checks for almost every item
  • The proof is text: "it returned 200"
  • Safety relies only on written rules

After v0.2.0

  • QA drives the real product with Playwright or Maestro
  • You get screenshots and a short video of each new flow
  • You check only what truly needs you
  • On Claude Code, a guard makes it ask before risky commands

What changes per role

Automation first

RoleNew
DeveloperAdds test hooks to new screens: accessible names, Flutter Semantics ids. Runs the end-to-end tests before hand-off
TesterWrites end-to-end tests into the repo: Playwright specs, Maestro flows, integration tests. Each is seen to fail first
QAAutomates each acceptance check, or says why it can't. Takes a screenshot per key state and a video per new flow
LeadYour update shows "What we checked" (evidence) and a short "What only you can check"
MarketerMay use QA screenshots, never ones that show personal data

Tools: Playwright (web), Maestro (mobile), Flutter integration tests, plus simulator and adb screenshots as a no-install fallback. On Claude Code: browser pane, iOS Simulator, Claude in Chrome (needs your OK).

Evidence

Screenshots in the repo, videos shown to you

Screenshots

Committed to docs/qa/<milestone>/screens/, one per key state, kept small.

Videos

In a git-ignored qa-artifacts/ folder. Shown to you in the session; you can attach them to the PR.

Privacy

Synthetic test data only. Tokens and personal data masked. No uploads (maestro record --local only), telemetry off.

Still needs you

A real device · your accounts · your IDE or debugger · trust or permission dialogs · payments and real emails · "does this look right?"

Host safety

Risky commands wait for your yes

Fine without asking

  • Work inside the project and its scratch folders
  • The project's own test, build and check commands
  • Stopping processes the agent started

Ask first: exact command, why, effect, undo

  • Deleting outside the project; git reset --hard, force-push, deleting branches
  • Killing other processes; wiping simulators or emulators; dropping databases
  • Global installs (once per tool, then recorded); sudo; curl | bash; new outside services

On Claude Code: a small hook in the plugin catches these and makes Claude Code ask you, even when a permission rule allows the command. It only ever asks and never blocks or decides for you. It runs on your machine with your permissions; the README says so.
