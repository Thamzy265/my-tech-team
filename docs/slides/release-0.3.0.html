What is in it

Six agents and a smarter lead

AgentModel · effortTools
Developer, tester, QASonnet · mediumall
ReviewerOpus · highread, shell, skills; no edit tools
MarketerSonnet · mediumfiles and web; no shell
Scout (lookups, not a role)Haiku · lowread, shell for search only

Lead

Dispatches each role to its agent. On a failed round: more effort, then Opus, then a blocker to you. Starts the developer on Opus for data-model, API, personal-data or multi-module items.

Your control

An "Agent models" line in Team setup changes any role's model or effort for a project. Other AI tools ignore the agents and keep using the skills.

Release and rollback

How it ships

1 Small PR: version 0.3.0, CHANGELOG, this deck→ 2 Merge after CI→ 3 Tag v0.3.0, publish the GitHub release→ 4 Check: a session on the tag lists 6 agents

Rollback

Release tags are protected, so a bad release gets a fix release (v0.3.1) rather than a deleted tag. Projects keep the version they pin; project-deck stays on v0.2.1 until its own session moves it.
