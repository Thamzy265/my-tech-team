# my-tech-team v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release my-tech-team v0.2.0. The team tests its own work with automation tools, shows screenshot and video evidence, and asks the PM before anything destructive on the host. On Claude Code, a guard hook makes it ask.

**Architecture:**
- A POSIX `sh` guard script (`hooks/guard.sh`) is registered as a Claude Code `PreToolUse` hook for Bash in `hooks/hooks.json`. It is unit-tested from Python and runs in CI on Linux and macOS.
- Skill changes are text: a shared "Host safety" section pasted verbatim into all six skills, an extended shared "Project setup" paragraph, new `references/automation.md` (qa) and `references/e2e.md` (tester), and edits to developer, lead and marketer files.
- Behaviour is tested the writing-skills way: RED/GREEN pressure scenarios on a sample project, plus one real Playwright evidence run.

**Tech Stack:** POSIX sh, Python 3 stdlib (`unittest`), Markdown skills, JSON hook config, GitHub Actions (pinned SHAs), Playwright (`@playwright/test` + Chromium, installed once with the PM's approval) for the evidence run.

**Spec:** `docs/superpowers/specs/2026-10-13-v0.2.0-automated-testing-design.md`. **Research:** `docs/research/test-automation.md`.

**Rules for every task:**
- Branch `feat/v0.2.0`. Never commit to `main`.
- Atomic Conventional Commits, each ending with a blank line + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Push only at the checkpoints marked **PUSH**.
- The release and every host-changing install need the PM's approval at the time.
- Worked examples in skills must not mirror the pressure scenarios.

]


def run_guard(command):
    payload = json.dumps({
        "hook_event_name": "PreToolUse",
        "tool_name": "Bash",
        "tool_input": {"command": command, "description": "test"},
    })
    return subprocess.run(["sh", str(GUARD)], input=payload, capture_output=True, text=True, timeout=10)


class Guard(unittest.TestCase):
    def test_risky_commands_ask(self):
        for cmd in MUST_ASK:
            with self.subTest(cmd=cmd):
                result = run_guard(cmd)
                self.assertEqual(result.returncode, 0)
                out = json.loads(result.stdout)
                hso = out["hookSpecificOutput"]
                self.assertEqual(hso["hookEventName"], "PreToolUse")
                self.assertEqual(hso["permissionDecision"], "ask")
                self.assertIn("my-tech-team guard:", hso["permissionDecisionReason"])

    def test_normal_commands_pass(self):
        for cmd in MUST_PASS:
            with self.subTest(cmd=cmd):
                result = run_guard(cmd)
                self.assertEqual(result.returncode, 0)
                self.assertEqual(result.stdout, "")

    def test_never_denies(self):
        for cmd in MUST_ASK:
            with self.subTest(cmd=cmd):
                self.assertNotIn('"deny"', run_guard(cmd).stdout)

    def test_empty_or_broken_input_fails_open(self):
        for payload in ("", "not json", "{}"):
            with self.subTest(payload=payload):
                result = subprocess.run(["sh", str(GUARD)], input=payload, capture_output=True, text=True, timeout=10)
                self.assertEqual(result.returncode, 0)
                self.assertEqual(result.stdout, "")


if __name__ == "__main__":
    unittest.main()

- [ ] **Step 3: Write `hooks/guard.sh`** and make it executable (`chmod +x hooks/guard.sh`):

```sh
#!/bin/sh
# my-tech-team guard (Claude Code PreToolUse hook for Bash).
# Asks the PM before risky commands. It never denies and fails open:
# if anything goes wrong it prints nothing, so normal permissions apply.
input=$(cat 2>/dev/null) || exit 0

has() { printf '%s' "$input" | grep -Eq -- "$1"; }
hasi() { printf '%s' "$input" | grep -Eiq -- "$1"; }

W='(^|[^A-Za-z0-9_./-])'   # start of a command word
reason=""

# Recursive delete of an absolute, home or parent path (temp folders are fine).
if has "${W}rm[[:space:]]+(-[A-Za-z]*[rR][A-Za-z]*|--recursive)" \
  && has "${W}rm[[:space:]][^|;&]*[[:space:]](/|~|\\\$HOME|\\.\\./)" \
  && ! has "${W}rm[[:space:]][^|;&]*[[:space:]](/tmp/|/private/tmp/|/var/folders/)[^[:space:]\"]+"; then
  reason="recursive delete outside the project"
elif has "${W}git[[:space:]]+reset[[:space:]][^|;&]*--hard"; then
  reason="git reset --hard discards uncommitted work"
elif has "${W}git[[:space:]]+clean[[:space:]]+-[A-Za-z]*f"; then
  reason="git clean deletes untracked files"
elif has "${W}git[[:space:]]+push[^|;&]*[[:space:]](-f|--force|--force-with-lease)([^A-Za-z-]|$)"; then
  reason="force-push rewrites remote history"
elif has "${W}git[[:space:]]+push[^|;&]*[[:space:]](--delete|:[A-Za-z0-9])"; then
  reason="deletes a remote branch or tag"
elif has "${W}git[[:space:]]+(branch[[:space:]]+(-d|-D|--delete)|tag[[:space:]]+(-d|--delete))"; then
  reason="deletes a branch or tag"
elif has "${W}git[[:space:]]+config[[:space:]]+--global"; then
  reason="changes global git config"
elif has "${W}(pkill|killall)[[:space:]]" || has "${W}kill[[:space:]]+-(9|KILL)" || has "xargs[[:space:]]+kill"; then
  reason="kills processes that may not belong to this task"
elif has "simctl[[:space:]]+(erase|delete)" || has "(-wipe-data|emulator[^|;&]*-wipe)" \
  || has "${W}adb[[:space:]][^|;&]*(uninstall|pm[[:space:]]+clear)"; then
  reason="erases a simulator, emulator or app data"
elif hasi "(psql|mysql|mariadb|sqlite3|duckdb|sqlcmd|mongosh)[^|;&]*(drop|truncate)[[:space:]]+(database|schema|table)"; then
  reason="drops or truncates database data"
elif has "${W}sudo[[:space:]]"; then
  reason="runs a command as administrator (sudo)"
elif has "(curl|wget)[^|]*\\|[[:space:]]*(sudo[[:space:]]+)?(ba|z|da)?sh([^A-Za-z]|$)"; then
  reason="pipes a download into a shell"
elif has "${W}brew[[:space:]]+(install|uninstall|reinstall|upgrade|tap)" \
  || has "${W}(npm|pnpm|yarn)[[:space:]][^|;&]*(-g|--global|global[[:space:]]+add)([^A-Za-z-]|$)" \
  || has "playwright[[:space:]]+install" || has "get\\.maestro\\.mobile\\.dev" \
  || has "${W}flutter[[:space:]]+upgrade" || has "${W}sdkmanager[[:space:]]"; then
  reason="installs or upgrades software on this machine"
elif has ">>?[[:space:]]*(~|\\\$HOME)/\\.(zshrc|bashrc|bash_profile|profile|zprofile|claude/)" \
  || has "${W}defaults[[:space:]]+write" || has "${W}(chsh|launchctl)[[:space:]]"; then
  reason="changes shell, system or Claude Code settings"
elif has "${W}(mkfs|shutdown|reboot)([[:space:]]|$)" || has "diskutil[[:space:]]+(erase|partition)" || has "${W}dd[[:space:]]+if="; then
  reason="can damage disks or stop this machine"
elif has "${W}(chmod|chown)[[:space:]]+-R[[:space:]][^|;&]*(/|~)"; then
  reason="changes permissions recursively outside the project"
fi

[ -z "$reason" ] && exit 0
printf '{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"ask","permissionDecisionReason":"my-tech-team guard: %s. Approve only if you expected this command."}}\n' "$reason"
exit 0
```
